# Housing Price Prediction

This project is my machine learning practice project where I worked on predicting housing prices using different preprocessing and model training techniques.

I built this project while learning from *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* to understand the complete machine learning workflow from data preprocessing to model evaluation.

## What I Worked On

In this project, I practiced:

- Loading and exploring housing dataset
- Handling missing values
- Feature engineering
- Data preprocessing using pipelines
- Feature scaling
- Train-test splitting using stratified sampling
- Model training
- Model evaluation
- Testing prediction accuracy

## Tools and Libraries Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

### 1. Data Exploration

First, I explored the dataset to understand:

- Different features
- Missing values
- Data distribution
- Correlation between attributes

### 2. Data Preprocessing

Performed preprocessing tasks like:

- Handling null values
- Encoding categorical values
- Feature scaling
- Creating new useful features

### 3. Data Splitting

Used stratified train-test split to preserve important feature distributions.

### 4. Model Building

Trained machine learning models on processed data.

### 5. Evaluation

Evaluated model performance using suitable metrics and compared results.
